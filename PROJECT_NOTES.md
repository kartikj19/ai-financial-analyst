# Project roadmap

## Version 1 — included
- Multi-PDF ingestion
- Chunking
- Local embeddings
- FAISS retrieval
- Gemini generation
- Conversational context
- Source/page citations
- Financial-domain prompt
- Streamlit UI
- Document summaries
- Environment configuration

## Version 2 — recommended resume upgrades
- Persistent FAISS index on disk
- OCR fallback for scanned PDFs
- Table extraction with a dedicated parser
- Hybrid BM25 + vector retrieval
- Cross-encoder reranking
- Retrieval evaluation with a labeled question set
- Authentication and per-user document collections
- PostgreSQL metadata store
- Docker deployment
- CI with GitHub Actions
- LangSmith/Langfuse tracing if desired
